# 多模态检索平台 — 需求文档

## 1. 项目概述

构建一个多模态智能检索与 RAG 问答平台，支持文本、图像、表格等多种模态的统一理解与检索。用户通过登录管理个人知识库，实现文档上传、智能检索、多模态问答等核心能力。平台支持多语言检索，LLM 与嵌入模型可灵活配置切换。

**核心理念：**
- **多模态统一**：文本、图像映射到同一语义空间检索
- **模型可插拔**：LLM / Embedding 多提供商可配置，运行时切换
- **多语言检索**：任意语言查询可检索任意语言内容（界面固定中文）
- **用户隔离**：每个用户独立管理知识库，数据严格隔离

## 2. 用户角色与权限

| 角色 | 权限 |
|------|------|
| 普通用户 | 管理自己的知识库、文档、检索与问答 |
| 管理员 | 用户管理、系统级模型配置、全局统计 |

## 3. 功能需求

### 3.1 用户认证模块

| 功能 | 详细描述 |
|------|---------|
| 用户注册 | 邮箱 + 密码，密码强度校验，邮箱唯一性验证 |
| 用户登录 | 邮箱 + 密码，返回 JWT（access + refresh token） |
| Token 刷新 | Access token 过期后通过 refresh token 自动续期 |
| 登出 | Token 黑名单失效 |
| 个人信息 | 修改密码、头像等基础信息 |

### 3.2 知识库管理模块

| 功能 | 详细描述 |
|------|---------|
| 创建知识库 | 名称、描述、可选配置（分块参数、嵌入模型） |
| 编辑知识库 | 修改名称、描述、配置 |
| 删除知识库 | 级联删除关联文档、向量、文件 |
| 知识库列表 | 展示用户所有知识库，文档数量统计 |
| 知识库详情 | 查看库内文档列表、存储占用、创建时间 |

### 3.3 文档上传与处理模块

| 功能 | 详细描述 |
|------|---------|
| 上传文档 | 支持 PDF / DOCX / PPTX / MD / PNG / JPG / TXT / HTML |
| 批量上传 | 多文件同时上传，异步处理 |
| 文档解析 | 提取文本内容、图片、表格、版面结构、标题层级 |
| 图像抽取 | 从 PDF/PPT 中抽取嵌入图片，存储到 MinIO |
| 表格提取 | 识别并结构化 PDF/PPT 中的表格 |
| 智能分块 | 按语义 / 段落 / 固定长度 / 递归分块，支持重叠窗口 |
| 向量化 | 文本块 → 文本嵌入；图像 → 视觉嵌入；表格 → 结构化嵌入 |
| 索引存储 | 文本块内容 + 稠密向量 + 稀疏向量 + 元数据 → ES 索引 |
| 状态追踪 | 上传中 / 解析中 / 分块中 / 索引中 / 完成 / 失败 |
| 重新处理 | 支持对已上传文档重新解析和索引 |

### 3.4 多语言检索模块

| 功能 | 详细描述 |
|------|---------|
| 多语言检索 | 中文查询可检索英文、日文等内容，反之亦然 |
| 多语言嵌入 | 嵌入模型支持多语言语义空间对齐（跨语言） |
| 跨语言语义对齐 | 不同语言的同义内容映射到向量空间相近位置 |
| 文档语言检测 | 自动检测文档/段落语言，索引时标记 |
| 多语言问答 | 用户可用任意语言提问，系统从多语言知识库中检索并回答 |

> 界面语言固定为中文，不预留 i18n 切换。

### 3.5 多模态检索模块

| 功能 | 详细描述 |
|------|---------|
| 文本检索 | 用户输入文本，返回相关文本块 + 图片 |
| 图像检索 | 以图搜图，返回相似图片及上下文 |
| 混合检索 | 向量检索（语义）+ BM25（关键词）融合排序 |
| 跨语言检索 | 中文查询可检索英文内容（多语言嵌入对齐） |
| 多粒度结果 | 段落级 / 图片级 / 表格级 / 文档级多层次返回 |
| 检索范围 | 指定单个或多个知识库检索 |
| 结果展示 | 高亮匹配内容、来源文档、页码、相关图片 |
| 过滤筛选 | 按文档、日期、类型等条件过滤 |

### 3.6 多模态 RAG 问答模块

| 功能 | 详细描述 |
|------|---------|
| 对话问答 | 基于知识库内容的流式智能问答 |
| 多轮对话 | 支持上下文关联的多轮追问 |
| 多模态引用 | 回答中引用原文段落和原图 |
| 溯源标注 | 每个回答标注来源文档、页码、置信度 |
| 对话历史 | 保存问答历史，支持查看和继续 |
| 多会话管理 | 创建 / 切换 / 删除多个对话 |
| 语言跟随 | 问答语言跟随用户输入或自动检测 |

### 3.7 文档与文件管理模块

| 功能 | 详细描述 |
|------|---------|
| 文档列表 | 展示知识库内所有文档，状态、上传时间、大小 |
| 文档预览 | 在线预览 PDF / 图片 / 文本 |
| 删除文档 | 级联删除 ES 索引和 MinIO 文件 |
| 文件管理 | MinIO 中原始文件、抽取图像的管理 |

### 3.8 模型配置模块（系统级）

| 功能 | 详细描述 |
|------|---------|
| LLM 管理 | 配置多个 LLM 提供商（OpenAI / 通义千问 / DeepSeek / Claude 等） |
| Embedding 管理 | 配置文本嵌入模型（BGE-M3 / OpenAI / Cohere / E5 等） |
| 视觉嵌入管理 | 配置图像嵌入模型（CLIP / SigLIP 等） |
| 多模态 LLM 管理 | 配置图像理解模型（GPT-4o / Qwen-VL / Gemini 等） |
| 默认模型设置 | 设置全局默认 LLM、Embedding、视觉模型 |
| 知识库级覆盖 | 知识库可指定使用特定模型，覆盖全局默认 |
| 模型健康检查 | 检测模型 API 可用性和延迟 |
| API Key 加密存储 | 所有密钥加密后存储 |

## 4. 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 单次检索 < 500ms，问答首字 < 2s（流式） |
| 并发 | 支持 50+ 并发用户上传与检索 |
| 安全 | JWT 鉴权、密码 bcrypt 加密、API Key AES 加密、用户数据严格隔离 |
| 可扩展 | 模块化设计，新模型提供商只需实现接口即可接入 |
| 存储 | 单用户支持 GB 级文档，支持水平扩展 |
| 部署 | Docker Compose 一键部署，配置外置 |
| 日志 | 操作日志、错误日志分级记录 |
| 多语言 | 检索层面多语言，界面固定中文 |
